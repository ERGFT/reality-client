# Reality Client — предварительная версия

Графический клиент на Rust и Slint для закреплённого Reality Core. Исходный код и актуальные инструкции: [github.com/ERGFT/reality-client](https://github.com/ERGFT/reality-client).

## Запуск

- **Windows:** запустите установщик `RealityClient-Setup-windows-x64.exe`; он установит GUI и нужные файлы ядра, добавит ярлык в меню «Пуск» и предложит запустить клиент. Для Windows TUN нужны права администратора. Системный прокси включайте только если он вам нужен.
- **Linux:** запустите `RealityClient` либо используйте `install-linux.sh`. Для TUN нужны `root` или `CAP_NET_ADMIN`.
- **Android:** это debug APK для ARM64. Android должен отдельно запросить разрешение VPN; установка APK сама по себе VPN не включает.

## Секреты и ограничения

VLESS-профили сохраняются в защищённом хранилище платформы. Полный JSON-конфиг может содержать незашифрованные секреты: ограничьте доступ к файлу и по возможности используйте `link_file`.

Это экспериментальная сборка. Проверенные версии ОС, контрольные суммы и ограничения конкретного пакета указаны в заметках к его GitHub Release. Наличие TUN-кода или успешная сборка не подтверждают работу сетевого интерфейса, системного прокси либо соединения с удалённым сервером.
