## Не проверено

- Сквозной трафик «клиент → настоящий сервер VLESS/REALITY → сайт» на **любой** платформе.
- Windows: системный прокси и TUN (Wintun) на чистой машине.
- Linux: TUN и маршруты, Secret Service на реальном рабочем столе, установщик.
- Android: `VpnService` и TUN на устройстве, `protect(fd)`, смена сети, отзыв разрешения.
- Регрессионный тест закрытия TUN-дескриптора на Linux (есть в скрипте сборки, не запускался отдельно).
- CI на GitHub Actions: ни одно задание не стартовало (ошибка биллинга аккаунта), поэтому результаты размещённых сборок отсутствуют.

## Известные ограничения

- Ядро закреплено по коммиту `ee68039` и собирается с локальным патчем
  (владение TUN-дескриптором); upstream vpn-core ушёл дальше.
- `rust-client/src/lib.rs` — монолит (около 3500 строк), требует разбиения.
- В git лежат бинарные файлы (`dist/RealityClient.exe`, `third_party/*.exe`,
  `*.zip`, `wintun.dll`); планируется убрать.
