# Reality Client v0.1.0-preview.12

## Изменения
- Исправлены статус после отключения Android VPN и опрос счётчиков через действующую Android-сессию.
- Выбор узла группы использует Android FFI-сессию; общая проверка параметров переиспользуется на всех платформах.
- Добавлены регрессионные тесты и подробный отчёт Android 16.

## Проверено до выпуска
Android 16/API36 в отдельном эмуляторе: ARM64 через ARM-трансляцию, HTTPS-подписка и ручной VLESS-профиль, обновление подписки, VLESS/REALITY/Vision через независимый локальный Xray, передача 256 КиБ с совпавшим SHA-256, отключение и повторное подключение. 123 локальных Rust-теста прошли, один пропущен.

Это лабораторная проверка TCP. Физические телефоны, зарубежный публичный IP, UDP/DNS и несколько членов selector-группы пока не проверены.

## Ограничения установки
Android APK пока подписан отладочным ключом CI. Ключ может отличаться от предыдущего релиза; установка поверх старого APK может отклоняться. Удаление приложения стирает локальные данные — сохраните ссылки заранее. Постоянная подпись ещё не настроена.
Windows installer не имеет коммерческой подписи: SmartScreen может показывать предупреждение неизвестного издателя. Защита Windows не отключается.

## English
Fix Android disconnect status and native traffic polling; use the Android-owned FFI session for selector changes. Regression tests and API36 runtime report included. Local TCP REALITY/Vision lab passed with payload hash verification. Physical phones, foreign public exit, UDP/DNS and multi-member selectors remain unverified. Debug APK signing is not persistent across CI runs; upgrades may reject a mismatched signing key. Windows installer is unsigned and may trigger SmartScreen.
