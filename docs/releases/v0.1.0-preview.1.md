# Reality Client v0.1.0-preview.1 — предварительная версия / preview

[Русский](#русский) | [English](#english)

## Русский

Первая публикуемая сборка графического клиента VLESS/REALITY на Rust и Slint. **Это предварительная версия:** она собрана и проверена автоматическими тестами, но ни разу не запускалась на реальном сервере. Не используйте её там, где нужна надёжность.

### Файлы

| Файл | Что это |
|---|---|
| `RealityClient-Rust-windows-x64.zip` | Windows x64: `RealityClient-Rust.exe`, `wintun.dll`, консольная программа ядра, лицензии |
| `RealityClient-Rust-android-arm64-debug.apk` | Android (arm64), **отладочная** сборка |
| `RealityClient-Rust-linux-x86_64.tar.gz` | Linux x86_64 с установщиком `install-linux.sh` |
| `SHA256SUMS-*.txt` | контрольные суммы SHA-256 каждого файла |

Проверка контрольной суммы: Windows — `Get-FileHash <файл> -Algorithm SHA256`; Linux — `sha256sum -c SHA256SUMS-linux-x86_64.txt`. Сравните с файлом `SHA256SUMS-*.txt` из этого же релиза.

### Установка

- **Windows.** Распакуйте архив в отдельную папку и запустите `RealityClient-Rust.exe`. Сборка **не подписана**: SmartScreen покажет предупреждение («Подробнее» → «Выполнить в любом случае»). Для TUN нужны права администратора и `wintun.dll` из архива; системный прокси включайте, только если он нужен.
- **Android.** Разрешите установку из неизвестных источников и откройте APK. Это отладочная сборка, подписанная временным ключом: когда выйдет подписанная версия, её придётся ставить после удаления этой. Android отдельно запросит разрешение VPN.
- **Linux.** `tar -xzf RealityClient-Rust-linux-x86_64.tar.gz`, затем `./linux-x86_64/install-linux.sh`. Для TUN нужны `root` или `CAP_NET_ADMIN` (см. [docs/PLATFORMS.md](https://github.com/ERGFT/reality-client/blob/main/docs/PLATFORMS.md)).

Вам понадобится своя VLESS-ссылка. Не публикуйте её в issue, журналах и скриншотах.

### Что проверено, а что нет

Проверено автоматически (GitHub Actions): сборка на Linux, Windows и Android, модульные тесты клиента (72), запуск ядра внутри процесса на Linux (локальный SOCKS-слушатель), состав пакетов.

**Не проверено:** трафик через настоящий сервер VLESS/REALITY на любой платформе; запуск `.exe` и APK на устройстве; TUN и системный прокси на Windows, TUN на Linux; `VpnService` и динамические цвета Material You на Android. Подробнее — [docs/STATUS.md](https://github.com/ERGFT/reality-client/blob/main/docs/STATUS.md).

Нашли ошибку — откройте issue (без ссылок, ключей и UUID). Исходный код ядра для этой сборки: репозиторий [ERGFT/vpn-core](https://github.com/ERGFT/vpn-core), коммит записан в `CORE-SOURCE.txt` в Windows-архиве и в `third_party/vpn-core.rev`.

## English

The first published build of the Rust + Slint GUI client for VLESS/REALITY. **This is a preview:** it is built and covered by automated tests, but it has never been run against a real server. Do not use it where reliability matters.

### Files

| File | What it is |
|---|---|
| `RealityClient-Rust-windows-x64.zip` | Windows x64: `RealityClient-Rust.exe`, `wintun.dll`, the core's command-line program, licences |
| `RealityClient-Rust-android-arm64-debug.apk` | Android (arm64), a **debug** build |
| `RealityClient-Rust-linux-x86_64.tar.gz` | Linux x86_64 with the `install-linux.sh` installer |
| `SHA256SUMS-*.txt` | SHA-256 checksums of every file |

To verify a checksum: Windows — `Get-FileHash <file> -Algorithm SHA256`; Linux — `sha256sum -c SHA256SUMS-linux-x86_64.txt`. Compare with the `SHA256SUMS-*.txt` file of this same release.

### Installing

- **Windows.** Unpack the archive into its own folder and run `RealityClient-Rust.exe`. The build is **unsigned**: SmartScreen will warn ("More info" → "Run anyway"). TUN needs administrator rights and the `wintun.dll` from the archive; turn the system proxy on only if you need it.
- **Android.** Allow installing from unknown sources and open the APK. This is a debug build signed with a temporary key: when a signed version comes out, you will have to uninstall this one first. Android asks for the VPN permission separately.
- **Linux.** `tar -xzf RealityClient-Rust-linux-x86_64.tar.gz`, then `./linux-x86_64/install-linux.sh`. TUN needs `root` or `CAP_NET_ADMIN` (see [docs/PLATFORMS.en.md](https://github.com/ERGFT/reality-client/blob/main/docs/PLATFORMS.en.md)).

You need your own VLESS link. Never post it in an issue, a log or a screenshot.

### What was checked and what was not

Checked automatically (GitHub Actions): the Linux, Windows and Android builds, the client's unit tests (72), starting the core in-process on Linux (a local SOCKS listener), the package contents.

**Not checked:** traffic through a real VLESS/REALITY server on any platform; running the `.exe` and the APK on a device; TUN and the system proxy on Windows, TUN on Linux; `VpnService` and Material You dynamic colours on Android. More in [docs/STATUS.en.md](https://github.com/ERGFT/reality-client/blob/main/docs/STATUS.en.md).

Found a bug? Open an issue (no links, keys or UUIDs). Source of the core for this build: the [ERGFT/vpn-core](https://github.com/ERGFT/vpn-core) repository; the commit is recorded in `CORE-SOURCE.txt` in the Windows archive and in `third_party/vpn-core.rev`.
