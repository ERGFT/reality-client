## Запрос владельца

Использовать оформление Clash Verge Rev как ориентир, включая крупные блоки
там, где это помогает, но сохранить собственный характер Reality Client.
Существующее Rust-ядро и поддержка Windows, Android, Linux остаются основой.

## Реализация

- Компактная боковая навигация на ПК и постоянный заголовок раздела.
- Переключение темы из верхней панели, общий тональный акцент и спокойные поверхности.
- Главная страница с карточкой подключения, выбранным сервером и статистикой.
- В разделе серверов две локальные вкладки: серверы и управление подписками.
- Отдельные действия добавления сервера и подписки с подходящими подсказками.
  Импорт по-прежнему автоматически распознаёт VLESS/HTTPS; смена вкладки не
  меняет выбранный сервер, действующее соединение и содержимое черновика.
- Явное пустое состояние подписок и серверов.
- На Android сохранены Material You, нижняя навигация и платформенные safe insets.

### Что брать из ориентиров

- Главная: компактная сводка, одна основная кнопка, выбранный сервер рядом,
  скорость и трафик ниже. IP-проверки различают обычный маршрут и прокси.
- Серверы: список с понятным выбором; подписка — отдельная сущность,
  импорт открывается явным действием. Не заставлять вводить ссылку повторно.
- Настройки: категория и короткие карточки вместо бесконечной ленты.
  Расширенный JSON доступен отдельно, обычное подключение не требует его.
- Телефон: нижняя навигация, поля не скрываются клавиатурой, действия не
  перекрываются камерой/статус-баром/жестовой полосой. Проверить портрет и
  альбомную ориентацию, масштаб шрифта и небольшой экран.

### Спецификация экранов и критерии готовности

| Экран | Изменение | Проверка готовности |
|---|---|---|
| Главная | Сессия, активный сервер, режим, скорость/трафик, IP | Статус запуска не выдаёт наличие Интернета; нет выдуманных IP/стран |
| Серверы | Поиск, список, выбор, редактирование, удаление | Фильтр не меняет индекс исходного профиля; выбранный сервер сохраняется |
| Подписки | Импорт HTTPS, обновление, название, ошибки | Черновик независим; атомарное обновление; активная сессия не обрывается |
| Соединения | Потоки отдельно от журнала, счётчики | Пустое состояние понятно; длинные адреса читаются; журнал скрывает секреты |
| Оформление | Светлая/тёмная тема, единые компоненты | Тема сохраняется и применяется на всех экранах |
| Подключение | Профиль/полный JSON, системный прокси | Режим очевиден; недоступные возможности объясняются |
| DNS/TUN | Fake-IP, TUN, Android приложения | Сохранение обновляет реальный конфиг; поддержка определяется платформой |

| Расширенные | JSON редактор, проверка, восстановление | Повреждённый конфиг не молча принимается; опасные действия подтверждаются |
| О приложении | Версия, автор, лицензия, репозиторий | Версия берётся из сборки; ссылка реально открывается |

### Технический порядок

Сначала `rust-client/ui/main.slint` и общие компоненты, затем модели и
обработчики в `rust-client/src/ui/`. Существующие callback использовать,
новые действия добавлять с валидацией и тестами. Перед фильтрацией списков
проверить отображение стабильного ID на исходный индекс. До сохранения
настроек проверить схему ядра и поведение платформенного адаптера.
Не заменять ошибки молчаливым fallback и не выдавать сохранение за применение
в уже запущенной сессии, если ядро не поддерживает reload.

Каждый этап: изменения → локальная сборка → проверки обработчиков → рендер
и визуальная проверка → отметка в плане. После всего пакета — Android16,
CI текущего head и слияние. Периодические запуски отключены; работа ведётся
по одной активной цели.

### Проверки всего пакета

- Все страницы/категории: светлая и тёмная тема, 360/412/600px и широкий ПК.
- Tab/Enter/Space, видимый фокус и доступные имена интерактивных элементов.
- Большой шрифт, длинные названия/адреса, пустые модели, ошибка, загрузка.
- Вставка буфера, VLESS и HTTPS импорт, повторное редактирование и отмена.
- Смена страницы/темы/подписки не рвёт лабораторную сессию и не сбрасывает выбор.
- Нативный Windows UI только в отдельном профиле; Android16 в эмуляторе.
- Проверки реального трафика — только изолированная лаборатория, без Happ.
- Отдельно записать: что проверено программным рендером, нативным UI,
  Android runtime, CI; физические телефоны не объявлять проверенными.

### Последовательность выполнения

1. Инвентаризация: сопоставить каждый элемент с Rust callback, сохранением и
   поддержкой закреплённого ядра на Windows/Linux/Android. Не добавлять
   декоративные переключатели или выдуманные страны, задержки и IP.
2. Общие компоненты: размеры, типографика, тональные поверхности, кнопки,
   карточки, поля, доступные имена, клавиатура и видимый фокус. Сохранить
   Material You и safe insets Android, проверить узкие/широкие окна.
3. Главная: состояние сессии, выбранный/действительно подключённый сервер,
   режим, скорость и объём трафика; сетевые проверки с честными обозначениями.
4. Серверы: удобный выбор и редактирование, поиск с сохранением стабильных
   идентификаторов. Подписки: отдельный импорт, обновление, переименование,
   удаление с подтверждением, загрузка и ошибки. Не сбрасывать активную сессию.
5. Соединения: отдельные представления активных потоков и журнала,
   статистика и понятные пустые состояния. Секреты не раскрывать.
6. Настройки: разделы оформления, подключения, DNS/TUN, маршрутизации,
   расширенной конфигурации и восстановления. Для отсутствующей функции
   показывать причину недоступности. Для сохранения — результат или ошибку.
7. Маршрутизация: домены/URL, IP/CIDR, direct/proxy/blocked по доступным
   выходам; Android package ID и выбор приложений. URL-путь не выдавать
   за отдельное правило HTTP. Изучить возможности удаления отдельных правил.
8. О приложении: версия, автор, репозиторий, лицензия, платформенные сведения.
9. Проверки: render всех экранов и категорий в обеих темах, размеры телефонов,
   клавиатура/фокус; нативное окно Windows с тестовым профилем, Android16
   в отдельном эмуляторе, CI Windows/Linux/Android актуального head.
10. Документация и PR: записать фактические проверки и ограничения,
    обновить двуязычные PLAN/STATUS; сливать только завершённый пакет после
    зелёного CI. Релиз — отдельная задача.
